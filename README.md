# Simple Todo List Project

## Files
- index.html: Page structure
- style.css: Styling and responsive layout
- script.js: Add, complete, delete, and filter tasks

## How to run
1. Extract the ZIP file.
2. Open the `todo_list_project` folder.
3. Double-click `index.html` to open it in your browser.

Tasks are kept in memory only and are cleared when the page is refreshed or closed.
